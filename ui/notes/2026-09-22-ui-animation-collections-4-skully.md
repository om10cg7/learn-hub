## 4サイト

| サイト | 内容（実サイト確認） |
|------|--------|
| Rare UI（rareui.com） | 無料・オープンソースの「珍しい」アニメーション付き React コンポーネント集（30+）。各コンポーネントは1ファイルで、shadcn CLI または MCP で導入可。Tailwind CSS＋Motion 製 |
| Obsidian UI（obsidianui.dev） | React＋Tailwind CSS のコンポーネントライブラリ。コンポーネント／ブロック／LPテンプレートを収録し、コードを見ながらカスタマイズする前提の作り。無料 |
| Design Spells（designspells.com） | 実プロダクトの「魔法のように感じるデザインの細部」を動画で集めたギャラリー（350件規模）。Notion Calendar の What's new フロー、Vercel／Dub.co のホバーイースターエッグ、Apple Music の404ページの iPod など、マイクロインタラクションの実例集 |
| Transitions.dev（transitions.dev） | UI トランジションのレシピ集（43+）。カードリサイズ、モーダル開閉、タブスライド、スケルトンローダー等をプロジェクトへそのまま入れられる形で提供。「UI transitions for AI agents」を掲げ、コードベースのモーションを採点して PR で修正する Transitions Motion Agent もある |

## 学び

- 既存のリソース系ノート（Abraham の目的・パーツ別10選、Vamshi の54サイト等）が「デザインの見た目を探す棚」だったのに対し、こちらは「実装にそのまま持ち込める動きの部品棚」に寄っている。Rare UI と Obsidian UI は React コンポーネントとして導入でき、Transitions.dev はトランジションのレシピ集、Design Spells は実プロダクトの細部の観察用、と役割が分かれる
- 特に Transitions.dev は、図鑑で学んできた個別の動き（ページ遷移8種、トグル、通知など）の「実装レシピ」をまとめて引ける棚として、既存ノート群とつながる
- 既存ノートとの重複はなし（4サイトとも初収録）
- リソース一覧系の先例（Abraham 10選、Rhushabh モバイル5選、Vamshi 54サイト等）どおり、新しい UI 用語・技法の追加はないため図鑑カードは追加せずノートのみ
