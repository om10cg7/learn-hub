# UIスタイル12種を同じ14コンポーネントで比較（Muhammad Ali）

- 出典：Instagram @muhammadalim_s（Muhammad Ali、AI advocate）のリール「12 UI Styles」（2026-11-14投稿）
  - https://www.instagram.com/reel/Dfug2YmzPTh/
  - キャプション要旨：「12 UI styles. Same 14 components. Zero designers」。全ピクセルと全アニメーションを Claude Fable 5.2 が書いたと明言。12種のスタイルプロンプト＋ワークフローはコメント「PACK」で DM 配布（プロンプト本文は投稿内にはなく未回収）
  - ハッシュタグは #uidesign #webdesign #claude #aidesign #glassmorphism #neumorphism #brutalism #vibecoding など
  - 内容は動画解析（media-understanding）とサムネイルで確認

## 12スタイル一覧（同じ14コンポーネントを各スタイルで描画）

| # | スタイル | 画面の特徴 |
|---|---|---|
| 01 | Liquid Glass | 光を屈折させる半透明の重ねガラス |
| 02 | Neumorphism | 白く柔らかく押し出されたコントロール |
| 03 | Neo-Brutalism | 原色・太い境界線・コラージュ配置 |
| 04 | Claymorphism | パステルの膨らんだ粘土質感 |
| 05 | Plasma Glow | ネオンのオーロラ光をまとうダークコンソール |
| 06 | Skeuomorphic Hardware | 実際に弾けるシンセ／音響機器のフェイスプレート |
| 07 | Retro OS | 1-bit の1980年代デスクトップ |
| 08 | Hand-drawn Sketch | 自分で描いていくスケッチブック風 |
| 09 | Bauhaus | 原色の幾何学図形 |
| 10 | CRT Terminal | 緑色蛍光体のテキスト画面 |
| 11 | Swiss Editorial | 雑誌グリッドのタイポグラフィ |
| 12 | Risograph | ピンク×イエローの孔版印刷風 |

- 締めは12種を並べた「The Pack」の一覧画面で、コメント誘導

## 学び

- 同じコンポーネント一式をスタイルだけ変えて並べる「統制比較」の見せ方。スタイル名を指定するだけで AI にここまで振り切った画面を出させる、という Fable 5.2 の作例でもある
- 12種の大半（Liquid Glass／Neumorphism／Neo-Brutalism／Claymorphism／スキューモーフィズム／CRT／Swiss／レトロOS／手描き）は図鑑に既収録。未収録だったのは Plasma Glow／Bauhaus／Risograph の3つで、カタログカード側にまとめて収録した
- 配布プロンプト本文は DM 限定で投稿からは取得できないため、今回はスタイルのカタログとして記録（プロンプト配布そのものが主題ではないので threads-prompt ではなく ui へ）
