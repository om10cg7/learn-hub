## 8種

| # | 値 | 意味 | 例 |
|---|------|------|------|
| 1 | pointer | クリックできる要素 | ボタンのホバー |
| 2 | text | 選択できるテキストの上 | テキストエディタ |
| 3 | move | 要素がドラッグできることを示す | ドラッグ用コンポーネント |
| 4 | not-allowed | 操作が許可されていない | 無効化されたボタン |
| 5 | grab | 要素がつかめることを示す | ドラッグ可能なカード |
| 6 | crosshair | 精密な選択 | 画像の切り抜きツール |
| 7 | wait | 読み込み中 | ローディング状態 |
| 8 | zoom-in | 拡大できる | 画像プレビューのホバー |

Pro Tip：カーソルの形で「ここで何ができるか」を視覚的に返すのが UX 改善になる（例：`button:hover { cursor: pointer; }`）。

## 学び

- カーソルは最小のフィードバック装置で、押せる／選べる／動かせる／禁止／待ち の5状態を形だけで伝えられる。名前シリーズ（図・日付ピッカー）と同系統の「状態の語彙カタログ」
- move と grab の違いが要点：move は「移動できる」方向性のあるドラッグ、grab は「つかめる」対象そのものへの言及。ドラッグ中は grabbing に切り替えるのが実務の型（このシートには未収録）
- not-allowed と wait は「できない理由」が違う（禁止 vs 処理中）。無効ボタンに wait を使うなどの取り違えを避けるための対比になっている
