## 名前の相棒プロンプト（要約）

- 自己返信のプロンプトは「Webの動き30個」のリストを含む。30個は動画の24種を土台に、フェードイン／スライドイン／ポップアップ／ホバー拡大／ボタンの色変化／無限スクロール／ローディング（スピナー）／プログレスバー／グラスモーフィズム／ホログラフィック／スライドショー／スプリットスクリーン／ホバーで画像切り替え／背景動画などを加えた構成（パララックスなど一部は重複掲載）
- 使い方：この返信を丸ごと ChatGPT や Claude に貼り、末尾に「作りたいサイト」か「見たことのある動き」を書く。すると、合う動きを表で提案し、選んだ案を Claude Code などコードを書くAIへ渡す指示文に直してくれる
- 指示の書き方のコツ（プロンプト内に含まれる要点）：
  - 動きの名前で伝える
  - 場所と動きをセットで伝える
  - 強さと速さもセットで伝える
  - 動きは1箇所につき1つにする
  - 全部に動きをつけない（絞る）
