# UI向けカラーパレット6種（同系色の明度ステップ型・第2弾）

- 出典：Instagram @uiuxaadi（Aadish Bansal）のカルーセル「8 stunning colour palettes for your next UI project!」（2026-11-12投稿、全6スライド）
  - https://www.instagram.com/p/DfpQF2RFN7w/
  - キャプションは「8 palettes」と言いながら8つの名前（Purple／Green／Amber／Rose／Mocha／Indigo／Electric Blue／Magenta）を並べているが、実際のスライドは6枚。以下は実スライドベースで記録する
  - 形式は全スライド共通：パレットの色相に合わせた光る背景の上に、ピル型スウォッチを重ね、各チップに HEX を白文字で表示
  - ユーザー指定スライド（img_index=4、0始まりの5枚目）はピンク系パレットのスライド。メディア解析のスライド順からの特定で、単体画像は取得できないため推定として扱う

## 6パレット（両端の HEX は解析で確認できた範囲）

1. **パープル**（表紙スライド、チップ全色を画像で実測）：`#00010D` → `#010326` → `#2D0140` → `#660273` → `#A305A6`。ほぼ黒の紫から鮮やかなマゼンタ寄り紫まで5段
2. **グリーン**：`#0F2A1D` 〜 `#E3EED4` の範囲（深緑から淡いグリーンまで）
3. **ブルー**：`#2078CF` 〜 `#000521` の範囲（鮮やかな青からほぼ黒のネイビーまで）
4. **インディゴ／バイオレット**：`#0B0F1A` 〜 `#F5F7FF` の範囲（ほぼ黒の藍からほぼ白のラベンダーまで、6種の中で最も明度幅が広い）
5. **ピンク**（ユーザー指定スライド）：`#2D0A1E` 〜 `#FFF3E6` の範囲（濃いプラム色から淡いクリームピンクまで）
6. **ブラウン／ベージュ（Mocha）**：`#3B2A1F` 〜 `#FFF9F0` の範囲（濃い茶からほぼ白のベージュまで）

## 既存ノートとの関係

- 図鑑118種目（notes/2026-11-14-color-palettes-5-uiuxaadi.md、投稿 DfuuYl7jc4U）とは別投稿（ショートコード・投稿日・スライド数が異なる）。同作者の同シリーズで、ブルー／グリーン／ピンクの3種は HEX 範囲まで同一のパレットが再掲されている
- こちらにだけあるのはパープル（`#00010D`〜`#A305A6`）／インディゴ／ブラウンの3種。逆に118種目側のティール＋アンバー系ミックスとパープル／ダスティローズ（`#190019`〜`#FBE4D8`）は今回の6枚にはない
- キャプションの8つの名前と実スライドの対応は今回も曖昧で、Amber と Magenta に対応する独立スライドは確認できない（118種目と同じ表記ゆれ）

## 要点

- 基本形は118種目と同じ「1色相の中で明度を刻む」モノクロマティック型で、新しい用語・技法の提示はないため、図鑑カードは追加せずノートのみとする（同作者のシリーズ変種の先例どおり）
- 使いどころは118種目と共通：ダークテーマの背景→面→ボーダーの階層設計にそのまま流用できる。今回分の追加価値は、紫系で彩度高めの終端（`#A305A6`）を持つ系統と、藍→ほぼ白まで振り切ったインディゴ系が増えた点
