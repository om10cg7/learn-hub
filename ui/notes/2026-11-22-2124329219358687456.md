# AIアプリの「考え中」表示をかっこよくする ThinkingOrbs（しん|AI×iOS開発）

- 出典：X @protoduct_ai（しん|AI×iOS開発、認証済み）の投稿（2026-11-22 11:28）
  - https://x.com/protoduct_ai/status/2124329219358687456
  - 主題は、AIアプリの処理中状態を見せる SwiftUI 向けローディング部品「ThinkingOrbs」の実物デモ
  - 添付は30秒の動画。iPhone 上のデモアプリで、点の集合が球状に回転・変形するローディング表示が切り替わる

## ThinkingOrbs の概要

- 点で描くローディング表示を9種類収録
  1. Working
  2. Searching
  3. Solving
  4. Listening
  5. Connecting
  6. Weaving
  7. Composing
  8. Breathing
  9. Shaping
- サイズは大小2種類（64pt／20pt）
- 1行で置ける手軽さが売り
- ライト／ダーク両対応

## 動画で分かる動き

- 基本形は、多数の点が球状に集まり、回転しながら形を変える「点描の3Dローダー」
- **Connecting** は点同士が線で結ばれ、星座のように動きが出るタイプ
- **Breathing** は点のリングがゆっくり形を変えるタイプ
- AI の「考え中」を、スピナーではなく状態名に沿ったモーションで見せる発想。Working／Searching／Solving のように処理フェーズの言葉と表示を対応させやすい

## 学び・所感

- ローディング表示を「待ち時間の穴埋め」ではなく、AI が今何をしているかを伝える UI として設計している点が要点。状態名の語彙（Working／Searching／Solving／Listening など）とモーションをセットにしている
- 既存のローダー8種ノートが「待ち時間の性質で選ぶ」整理だったのに対し、こちらは AI／エージェント向けに特化し、処理フェーズごとの見せ方を部品化した実例
- 64pt の主表示と20pt の小型表示を用意しているため、画面中央の待機表示だけでなく、チャット行内やボタン周辺のような小さな処理中表示にも転用しやすい構成
