## 画面構成

| 画面 | 中身 |
|------|------|
| ホーム（医師を探す） | 見出し「Let's find your doctor」の脇に検索とフィルタ。医師カード（写真・専門・プロフィールへの導線）が並ぶ |
| 受診カテゴリ | General（$89〜）／Specialist（$289〜）／Medical Tests（$179〜）／Therapeutic（$55〜）と、開始価格を各カテゴリに表示 |
| 医師プロフィール | Dr. Sarah Johnson（Medicine Specialist）：評価4.6、経験8年、患者数・レビュー数などの実績指標を集約。資格情報も同じ画面に |
| 予約 | 日付ピッカー＋横スライド式の時刻セレクタ → 「Book Session」ボタン1つで確定 |
| 連絡手段 | 電話／ビデオ／チャットの3ボタンをプロフィールに併置 |
| ビデオ通話 | 通話画面（10:54経過、参加者2名のタイル表示） |

## 学び

- 医療系は「まず信頼、次に予約の手軽さ」の順で設計する：プロフィールに評価・経験年数・患者数・レビュー数を同じ画面に集め、判断材料を画面遷移なしで揃えている
- 価格の見せ方：カテゴリごとに開始価格（〜$）を出すことで、詳細を開く前に費用感が掴める。不安の大きい医療では特に効く型
- 予約の最終ステップは「日付＋時刻＋ボタン1つ」に絞り、迷わせない。同作者のフローリストアプリ（写真主導・下部のピルに主アクション）と通じる「主アクションは1つに集約」の発想
- 淡いブルー＋白、角丸カード、白衣の医師写真で「臨床的で冷たい」印象を避け、落ち着いた信頼感に寄せている
