## 8種

| # | 名称 | 向く場面（動画・キャプションの定義） |
|---|------|------|
| 1 | Pull down（プルダウン） | 引いて更新する定番型。モバイルのリスト向け。インジケータがスライドして現れる |
| 2 | Elastic pull（弾性プル） | 引く量に応じて伸びる遊びのあるドラッグ表現 |
| 3 | Release cue（リリースキュー） | 「ここで離せば更新」と合図を出し、離すタイミングを迷わせない |
| 4 | New posts pill（新着ピル） | 「新着あり」のピルを表示し、読んでいる位置を失わせない |
| 5 | Live insert（ライブ挿入） | リアルタイムフィード向け。新着をその場で差し込む |
| 6 | Auto-load（自動読み込み） | 無限スクロール向け。末尾に着くと自動で次を読む |
| 7 | Load more（もっと見る） | ユーザーが自分のペースで制御したいときのボタン型 |
| 8 | Refresh button（更新ボタン） | ダッシュボードや Web アプリ向けの明示的な更新ボタン |

## 学び

- 選び方の軸は「更新の主導権を誰が持つか」と「読んでいる位置（文脈）を守るか」。Pull down／Load more／Refresh button はユーザーが能動的に更新する型、Auto-load／Live insert はシステムが自動で流し込む型、その中間に New posts pill（自動で来るが適用はユーザーが押してから）がある
- New posts pill は「新着を流し込むと読む位置がずれる」という無限フィードの弱点への回答で、SNS フィードで標準形になっている
- Release cue は Pull down の弱点（離すタイミングが分からない）を補う合図の設計で、プル系は「引く→合図→離す→更新中表示」の一連で名前が付けられている
- AI への指示でも「New posts pill で新着を知らせて」「Auto-load でなく Load more にして」など名前で指定できる、同作者の名前シリーズ共通の効用
