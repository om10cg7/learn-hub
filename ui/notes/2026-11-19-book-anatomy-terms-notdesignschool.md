# 本文を構成する要素（紙ものデザインの部位名）NOT DESIGN SCHOOL

- 出典：YouTube Shorts、NOT DESIGN SCHOOL | 経験者向けデザインスクール（@NOTDESIGNSCHOOL）の動画「本文を構成する要素」（2026-11-19投稿、37秒）
  - https://youtube.com/shorts/m6oF8bt2qiQ
  - ウェビナー「基礎から学ぶ紙ものデザイン」からの切り抜き。プロンプトや手順の紹介はなく、用語解説のみ
  - 表紙以外の部分を「本文」と呼び、その構成要素を順に解説する内容

## 構成要素（登場順）

| # | 名称 | 説明 |
|---|------|------|
| 01 | 見返し | 遊び紙とも呼ばれる |
| 02 | 扉 | 最初に来る大きなタイトルのページ |
| 03 | 扉文 | まえがき |
| 04 | もくじ |  |
| 05 | 中扉 | 小扉とも。章の区切りページ（第1章・第2章など） |
| 06 | 本文 |  |
| 07 | あとがき | 著者の感想や編集後記が入ることもある |
| 08 | 索引 |  |
| 09 | 奥付 | 発行日・発行者・印刷所などの出版情報 |
| 10 | 見返し | 本の末尾にも見返しが来る（01と同用語） |

- ユニークな用語は9つ（見返しが冒頭と末尾の2回登場して全10項目）

## 図鑑との対応

- 9用語とも図鑑に未収録（扉・奥付・見返し・もくじ・中扉・扉文・あとがき・索引・本文のいずれも単独カードなし）
- 未収録が9件中9件と全数を占めるため、@PTNaomasa「部品と動きの名前24」、@kawai_design「Webサイトの『あの部分』の名前20」、@aldoxmotion「アニメーションの12原則（後半）」の先例に倣い、用語集全体を図鑑カード1枚として追加した（v3.61、全122用語、layout カテゴリ）。個別用語ごとのカード化はしていない

## 学び・所感

- @kawai_design の「Webサイトの『あの部分』の名前20」が画面／ページの部位名だったのに対し、こちらは紙の本の部位名。対象は違うが核は同じで、「名前で頼めば一度で伝わる」という指示語彙の整備
- 並びが本の物理的な綴じ順そのもの（見返し→扉→扉文→もくじ→中扉→本文→あとがき→索引→奥付→見返し）になっており、部位名をバラバラに覚えるのではなく本の構造の流れとして覚える設計
- 「本文」が表紙以外のすべてを指す総称であると同時に、構成要素の1つ（狭義の本文）でもある点が紛らわしい。二つの意味の使い分けが実務での指示の要点
- Web のページアナトミー（ヘッダー／ヒーロー／フッター等）と並ぶ、媒体ごとの「部位名の語彙」。紙ものデザインの依頼・指示でも同じく名前の有無が伝達精度を左右する
