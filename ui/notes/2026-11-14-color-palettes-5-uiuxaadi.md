# UI向けカラーパレット5種（同系色の明度ステップ型）

- 出典：Instagram @uiuxaadi（Aadish Bansal）のカルーセル「6 stunning colour palettes for your next UI project!」（2026-11-14投稿、全5スライド）
  - https://www.instagram.com/p/DfuuYl7jc4U/
  - キャプションは「6 palettes」と言いながら8つの名前（Electric Blue／Indigo／Purple／Green／Amber／Rose／Mocha／Magenta）を並べているが、実際のスライドは5枚。以下は実スライドベースで記録する
  - 形式は全スライド共通：パレットの色相に合わせた光る背景の上に、ピル型スウォッチを5〜7枚重ね、各チップに HEX を白文字で表示

## 5パレット

1. **ブルー**（表紙スライド、HEX 実測）：`#2078CF` → `#0E4EB2` → `#011F65` → `#020C47` → `#000521`。鮮やかな青からほぼ黒のネイビーまで5段
2. **グリーン**：`#0F2A1D` 〜 `#E3EED4` の範囲（深緑から淡いグリーンまで。両端の値のみ解析で確認）
3. **ティール＋アンバー系ミックス**：`#1A1F2B` 〜 `#FAF3E0` の範囲（ダークティール、ターコイズ、黄、オレンジ、クリームの混合。他のパレットと違い単色相ではない）
4. **ピンク／モーヴ**：`#2D0A1E` 〜 `#FFF3E6` の範囲（濃いプラム色から淡いクリームピンクまで）
5. **パープル／ダスティローズ**：`#190019` 〜 `#FBE4D8` の範囲（ほぼ黒の紫から淡いローズまで）

## 要点

- 基本形は「1色相の中で明度を刻む」モノクロマティック型。2026-11-02 の同作者プレミアムパレット9種（同系色ステップ＋アクセント1色）と同じ系譜だが、今回はアクセント色なしの純粋な明度グラデーションが中心で、ダークテーマの背景→面→ボーダーの階層設計にそのまま流用できる
- チップをずらして重ねるピル型の並べ方は、グラデーションの連続性が一目で伝わる見せ方。背景にも同色相のグロー（発光）を敷いて世界観を統一している
- 3枚目だけが複数色相のミックスで、他4枚の単色相ルールから外れている点に注意（キャプションの Amber はこの枚が対応するとみられる）
