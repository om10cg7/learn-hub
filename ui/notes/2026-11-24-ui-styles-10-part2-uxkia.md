# 同じe-wallet画面を10スタイルで着せ替える Part 2（ux.kia）

- 出典：Instagram @ux.kia（Kia、UXデザイナー、ジャカルタ）のリール「10 style UI yang wajib kamu tahu, part 2」（2026-11-21投稿、インドネシア語）
  - https://www.instagram.com/reel/DgBWpzxgXuC/
  - 内容は動画解析で確認。同じ e-wallet（電子マネー）のホーム画面を10スタイルで着せ替え、左の一覧が連動してハイライトされる構成。締めは10種のグリッド一覧
  - プロンプトは「STYLE」コメントで配布（未回収）

## 10スタイル

| # | スタイル | 見た目の要点（動画解析より） |
|---|---|---|
| 01 | Liquid Glass | 半透明の紫〜ピンクのグラデーション |
| 02 | Material You | 柔らかい緑のダイナミックカラー |
| 03 | Terminal | 黒背景＋緑の等幅文字、ハッカー画面風 |
| 04 | Hand-drawn | スケッチ線と手書きフォント |
| 05 | Y2K Chrome | メタリックブルーの球体と光沢クローム |
| 06 | Bauhaus | 赤・黄・青の原色ブロックと大胆な幾何学 |
| 07 | Pixel Art | レトロな8ビットのドット絵 |
| 08 | Aurora Gradient | パステルのオーロラ状グラデーション |
| 09 | Vaporwave | ネオンピンク／紫＋夕景グラフィック |
| 10 | Manga | 白黒の漫画風、ハーフトーンと吹き出し |

## 学び・所感

- 前提が「同じ画面・同じ機能」で、変わるのは皮だけという対照実験。スタイル名がそのまま指示語彙になるという点は、既存の「デザインスタイルの名前9種」（@우디）のノートと同じ主張で、こちらは金融アプリの実画面で示している分、適用イメージが具体的
- 顔ぶれは定番（Liquid Glass／Material You）に、Terminal、Hand-drawn、Manga のような「世界観の移植」系が混ざる。機能UIに漫画のハーフトーンと吹き出しを持ち込むような、様式の越境が面白さの核
