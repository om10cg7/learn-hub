# アニメ風UIライブラリ「Sakuga VFX」（Animmaster）

- 出典：Instagram @animmaster_studio（Animmaster）のリール（2026-11-24投稿）
  - https://www.instagram.com/reel/DgHqphRRXo4/
  - 内容は動画解析で確認。リンクは「LIB」コメントで送付（未回収）
  - ライブラリの正体はコメント欄の複数ユーザーの指摘で特定：**Sakuga VFX**（作者 Justin Finkelman、https://sakuga-vfx.vercel.app）。投稿者自身の明示ではないため、その旨を記録する

## 中身

- ブラウザ上のコンポーネント一覧をカーソルで実際にクリックして見せる実演型。並ぶのは Primary／Secondary ボタン、トグル、スライダー、チェックボックス、ラジオ、テキスト入力、タブ、評価スター、プログレスバー、トースト通知
- 各要素が、アニメ風の誇張した効果で反応する：漫画的な爆発、キラキラ（スパークル）、集中線のようなモーションライン
- 画面上のキャプションは「I found coolest Anime style UI Library」

## 学び・所感

- 通常のUIライブラリが「状態変化を分かりやすく」するのに対し、こちらはフィードバックそのものを作画（sakuga）の快感に振り切ったもの。クリックの手応えを、正確さではなく気持ちよさで設計している
- ボタンやトグルなど最も基本の部品にだけ適用されているのも要点で、派手な効果は「押した瞬間」の短い時間に閉じ込めるからこそ実用に耐える、という線引きが見える
