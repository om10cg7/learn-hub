## 5サイト

| サイト | URL | メモ |
|--------|-----|------|
| AppLlama | appllama.io | モバイルアプリUIのスクリーンショット集 |
| 60fps | 60fps.design | 「best-in-class apps の delightful details」を集めたコレクション。Shots／Apps／App Sites／Motion の4棚＋カテゴリフィルタ。動き（Motion）まで棚があるのが特徴 |
| Mobbin | mobbin.com | 実アプリの画面・フロー検索の定番。既存ノート（リソース50、デザイナー向け54、インスピレーション10）にも収録済みの唯一の重複 |
| AppShots | appshots.design | アプリのスクリーンショットギャラリー |
| AppKittie | appkittie.com | アプリUIのスクリーンショット集 |

## 学び

- 既存のリソース系ノートが「デザイン全般」の棚だったのに対し、こちらはモバイルアプリの実画面リファレンスに特化した5件だけの最小構成（タイトルの MVP = 最小実用セット）。Mobbin 以外の4件は既存ノートにない新規
- 60fps のように「Motion」を独立した棚として持つギャラリーは、静止画だけでなく画面遷移・マイクロインタラクションの実例を引く用途に向く
