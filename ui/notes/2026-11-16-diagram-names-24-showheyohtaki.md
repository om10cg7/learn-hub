## 学び

- 核は同作者のモーション演出名シリーズと同じ「名前で頼めば AI が再現できる」という語彙の整備で、対象が動画演出から資料作成（図解・グラフ）に広がった版。図解は特に「いい感じにまとめて」では出てこないため、名前指定の効果が大きい
- 24個は「整理する図／数字を見せるグラフ／流れと全体を見せる図」の3分類×8個。資料作成で実際に使う定番どころを押さえた実用的な選定
- 作者のライブラリ「Motion Prompt」（https://showheyohtaki.github.io/motion-prompt/ 、GitHub: showheyohtaki/motion-prompt、MIT）は今回で全10パック・240個（モーショングラフィックス／カメラワーク／UIパーツ／LP・Web演出／写真表現／各第2弾／画像生成のアートスタイル／図解・グラフ）。Claude Code や Codex には Skill として導入できる（`npx skills add showheyohtaki/motion-prompt`）
- 同シリーズの既収録分: モーショングラフィックスの演出名24種・第2弾（notes/2026-10-19-motion-techniques-24-showheyohtaki.md、#121〜#144）
