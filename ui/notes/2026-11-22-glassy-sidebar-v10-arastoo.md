# グラス質感サイドバー V10「Aurora」（Arastoo）

- 出典：Instagram @code.xr（Arastoo）のリール「Glassy Sidebar V10」（2026-11-22投稿）
  - https://www.instagram.com/reel/DgC6ruhT2NZ/
  - 内容は動画解析で確認。実装は React.js / CSS3 / HTML5、ソースコードは「Code」コメントで配布の形式
- 関連：notes/2026-11-08-glassy-sidebar-v7-arastoo.md（同じ作者の V7。あちらは明るいリビング背景に浮くピル型で、ウィジェット内蔵ランチャー型だった。本 V10 はダークテーマの業務ダッシュボード型で、別バージョンとして分ける）

## 中身

- ダークブルーのグラデーション背景（星のような粒子入り）に浮く、半透明グラスモーフィズムの縦サイドバー
- 初期状態はアイコンのみの細いバーで、操作で展開すると「Aurora」というプロダクト名のフルナビゲーションパネルになる
- 展開時の構成：Search、Home、Measure、Analyze、Report と、Projects セクション（Solar rollout、Fleet electrifica…、Supplier audit）— 炭素・エネルギー系の業務ダッシュボードを想定した項目立て
- カーソルのホバーでホバー状態と展開の挙動を見せるデモ形式
- 画面下部にはコードエディタが映り、サイドバーの状態に関する React／TypeScript のコードが見える（全文は読み取れず）

## 学び・所感

- V7 と比べると方向が違う：V7 は「カレンダーや音楽プレイヤーを内蔵したランチャー」だったのに対し、V10 は Search＋分析系メニュー＋プロジェクト一覧という、業務ダッシュボードの標準形に寄せている。グラスの質感は共通でも、想定プロダクトで中身の設計が変わる好例
- 項目名が Measure／Analyze／Report と動詞で揃っているのも業務UIらしい。アイコンだけの初期状態から展開する2段構成は V7 と共通の作法
