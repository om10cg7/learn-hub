## 内容

「Funil de projetos（プロジェクトのファネル）」と題したカンバンボードの画面ツアー。ダークなステージ上に Web アプリ画面が映り、下部にコードエディタ（funil.js）が常時表示される構成（@code.xr のダッシュボード群と同じ型）。

ボードの列（オーダー家具の営業工程）:

- **Orçamento（見積もり）** → **Projeto 3D（3D設計）** → **Proposta（提案）** → **Fechado（成約）**
- 各カードに顧客名と金額。合計表示は R$ 123,900

デモの流れと自動化:

- カードを Proposta から Fechado へドラッグすると、緑の「Projeto fechado!（成約！）」通知＋紙吹雪アニメーションが出て、集計指標が更新される
- コード側の見せ場は2関数。`aoSoltar`（ドロップ時：ステージが fechado なら WhatsApp でメッセージ送信 `whatsapp.enviar`）と `verificarParados`（最終更新からの日数を数え、停滞案件にフォローアップ送信）
- キャプションの事例：R$ 38,000 のマンション一式の見積もりが提案段階で5日止まるとカードが赤くなり、システムが WhatsApp で自動フォローアップ → 返信が来て成約・施工日程まで決まった、という営業ストーリー

## 学び・所感

- 記録の要点は「停滞の見える化＋自動フォロー」のパターン。カンバンのカードが止まった日数で赤く変わる＝鮮度（エイジング）の色表現で、放置案件をボード上で一目で炙り出す。CRM の常套だが、色変化→自動連絡までを1画面のデモでつないで見せる構成が分かりやすい
- 成約時の紙吹雪＋通知は、業務画面における祝祭フィードバック（celebration feedback）の実例としても使える
- カンバン自体は既知の型で新しい用語・技法の追加はないため、先例（Admin Dashboard V7／Ember Dashboard V29 等の画面デモ系）どおり図鑑カードは追加せずノートのみ
- 数値・事例（R$ 38,000 の成約ストーリー）は作者の販促上の主張で、裏取りはしていない
