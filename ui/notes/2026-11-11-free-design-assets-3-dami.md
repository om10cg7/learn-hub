## 学び

- 切り口は「3Dアイコン／人物イラスト／ロゴのダミー」と、UI制作でそのまま差し込む部品の種類で分かれている。特に UI Logos は実ブランドのロゴではなく、モックアップの見栄えを整えるためのプレースホルダーという位置づけが実務的
- 後半2枚は素材ではなく宣伝で、最終枚の Flutter ガイド広告は @flutterdeviser.agency 共有の「UI VS UX」ノートの最終スライドと共通するが、素材3選の部分は既存ノートにない新規内容
- リソース一覧系の先例（Griffin の UI ライブラリ4選、Abraham のインスピレーション10選等）どおり、新しい UI 用語・技法の追加はないため図鑑カードは追加せずノートのみ
