## 内容

家計・金融系ダッシュボードの画面ツアー。黒背景のステージ上に画面が切り替わり、技術は React.js／CSS3／HTML5 とされ、ソースは「Code」コメントで配布（コメント欄では bio 内リンクへ誘導。無料ではないとの指摘もあり）。

動画で巡る画面（解析より）:

- **ホーム** — 「Good morning, Code XR」の挨拶＋残高カード（$193,091.82、$640、$577）
- **Reports** — 収入／支出チャートとカテゴリ別支出
- **Savings & Goals** — 貯蓄合計 $26,804.87 と進捗サークル
- **Activity** — 取引リスト

画面下にはコードエディタが常時表示され、React／TypeScript で framer-motion と lucide-react を import した StatCard コンポーネントが見える（シリーズ共通の型）。

コメント欄の反応は質感への称賛が中心で、ほかに「サイドバーと下部ナビが重複していないか」というユーザビリティ面の指摘もあった。

## 学び・所感

- 同作者のダッシュボード量産シリーズの新バリエーション。今回はグラスモーフィズムではなく、エンボスや影で実物の触感を再現するスキューモーフィズムがテーマ。ただしスキューモーフィズム自体は図鑑収録済みの用語で（Fateh Zid のステッパーカウンター作例でもノートのみの先例あり）、新しい用語・技法の提示はないため、先例（Admin Dashboard V7／Glassy Dashboard V30／Ember Dashboard V29）どおり図鑑カードは追加せずノートのみ
- キャプションの「革の質感」は実画面では確認しづらく、宣伝文句と実画面の差として記録する。引き続き映像の中身で記録する
