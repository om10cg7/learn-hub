## 要約

技術解説アニメーション。AI開発の表側は Python（PyTorch、Hugging Face）が中心だが、裏側の中核部品は Rust へ書き換えが進んでいる、という話。具体例は2つ：OpenAI の Codex CLI（TypeScript→Rust）と、Hugging Face の Tokenizer（Python→Rust）。

理由の説明：

- トークナイザーは AI への全リクエストでテキストを処理するため、インタプリタで1行ずつ実行する Python は遅い
- C／C++ 級の速さには機械語への事前コンパイルが要るが、C／C++ は手動のメモリ管理（free など）が必須で、解放済みメモリを使うバグ（use-after-free）を攻撃者に突かれうる
- Rust はメモリの所有者を1つに限定し、変数がスコープを抜けたら自動解放、エラーはコンパイラがビルド時に検出する — 「C級の速さを安全に」
- 代償はコンパイル時間の長さで、素早い試作には Python の方が向く

結論は「AIがコードを書く時代でも、言語の特性を理解することが技術選定に効く」。技術の仕組み解説が主題のため etc に収録。

## 学び・所感

- 移行先の共通点はどちらも「毎回必ず通る細い関所」（CLI 本体、トークナイザー）で、全体を書き換えるのではなく、頻度×コストの高い部品から Rust 化するという現実的な判断が例から読み取れる
