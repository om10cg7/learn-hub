# 27. 自分の写真をセクシーな映画ポスター風ポートレートに（モノクロ＋赤リップのセレクティブカラー）

- 投稿者: とも（SNS年商1億の副業アドバイザーとも）@sns_tomo
- 投稿: https://www.threads.com/@sns_tomo/post/DbscyXGjKOm （2026-08-06、単一画像、いいね173）
- 共有リンク: https://www.threads.com/share/BAcC9Qu8oQ
- プロンプトの配布元: 作者本人の返信（投稿直下のコメント）から全文を回収した
- 使い方: 入力は ①添付写真 ②NAME（英字）。自分の写真を添えて、ポスター下部に入る名前を指定する

## 要約

添付した人物写真をもとに、映画ポスター／VOGUE 表紙風のグラマーポートレートを生成するプロンプト。核の指定:

- 人物は添付写真を忠実に再現し別人化禁止。構図・手の角度・指の形・顔半分の隠れ方まで維持する
- 顔と手が主役の超接写。少し顎を上げ、こちらを見下ろすような魅惑的で自信ある視線。マリリン・モンローを思わせる上品でセクシーな表情
- 全体は高級感あるモノクロ、唇だけクラシックレッドのセレクティブカラー。黒背景にドラマチックなスポットライト、85〜135mm・f1.4 の極浅い被写界深度
- 画面下 20〜25% は黒い余白を取り、下部中央に入力した NAME を大きく配置。太めの高級セリフ体、半透明ホワイトガラス風ロゴ（白い透かし、クリアなガラス質感、柔らかな発光、上品な光沢、繊細なぼかし）で映画ポスターのタイトルのような存在感にする
- 文字の下に小さく「Luxury Edition」。品質指定は HDR、8K、Ultra Detailed、Masterpiece
- 作例では NAME に「TOMO」が入り、下部に「TOMO LUXURY EDITION」と表示されている
