## 要約

X投稿（添付は同じ内容を図解したインフォグラフィック）。「Claude はもはや単なる AI チャットボットではなく、自律型 AI エージェントを構築するためのエコシステム全体になりつつある」という主張のもと、2026年に AI エンジニアリングを学ぶ人向けに、Claude の全体像を6つの層で整理したロードマップ。チャットボットと本番運用できるエージェントシステムの差は、この層構造を理解しているかどうかだ、という趣旨。

## 6層の内訳

| 層 | 位置づけ | 構成要素（投稿内表記） |
|---|---|---|
| 1. AI Models | 脳 | Claude Opus／Sonnet／Haiku |
| 2. Agent Frameworks & Tools | 構築の道具 | Agent SDK／API Core／MCP（Model Context Protocol） |
| 3. Production & Workspace | 仕事場 | Claude Code／Cowork／Claude Design／Claude Security |
| 4. Memory & Storage | 記憶 | Claude Context Store／Memory Store |
| 5. Security & Governance | ガードレール | Constitutional AI Checker／RLHF Compliance Engine／Adversarial Defense Layer |
| 6. Deployment & CI/CD | 届ける仕組み | Anthropic Inference Cluster／Research Workflow Pipeline／Model Safety Evaluator |

要点:

- 第2層は、Claude がプロンプトに答えるだけでなく、推論し、ツールを使って行動するための土台と位置づけられている。
- 第4層は「覚えられないエージェントは改善できない」という考え方で、永続的な記憶を持たせる層とされる。
- 第5・6層は、企業利用に耐える安全性・ガバナンスと、安全にモデルを出荷・改善し続けるための配信基盤として整理されている。
