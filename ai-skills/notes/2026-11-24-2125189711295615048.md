## 要約

X投稿（2026-11-24 20:28、添付は動画33秒）。「Muse + 無料の GitHub リポジトリ14件でモーションデザインスタジオを作る」と題し、After Effects のサブスクなしで、2Dアニメーション／3D／AI動画／モーショングラフィックス／サウンドまでをコードと AI エージェントで作るためのスタックを、3カテゴリ14件で紹介したリスト。締めのワークフローは「animate → simulate → visualize → draw → build 3D → generate video → add sound」。

添付動画は「Muse | Motion Studio」のダッシュボードで、14件のカードが Helix／Stack／Grid 表示で巡回するデモ（この投稿自体がスタックの作例になっている）。

投稿内の注意書き（いずれも投稿内表記で、個別に裏取りしていない）: 全14件を GPU なしの Muse でテスト済み（一部は環境調整が必要）／MusicGen のモデルは非商用のみ／Remotion は3人までのチームは無料。スター数合計557K等の数値も動画内の表示に基づく投稿内表記として扱う。
