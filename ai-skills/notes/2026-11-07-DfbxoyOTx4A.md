## 要約

リール動画（内容は解析で確認）。Claude Code で作った自分専用のAIアシスタント「Jarvis」のアップデート紹介。これまで Jarvis は ChatGPT や Claude など他のAIとの会話履歴（記憶）を参照できなかったが、3ステップで参照できるようにしたという内容。

Step 1: ChatGPT の設定 > データコントロールから会話履歴をエクスポートする。Step 2: エクスポートしたファイルを Claude Code に渡し、会話ごとに分割して3行の要約を作らせ、Obsidian の「AI's Memory」というフォルダに保存させる。Step 3: CLAUDE.md に「回答前に必ずこのフォルダを読む」というルールを書き、Claude が毎回その記憶を踏まえて答えるようにする。画面内では 2026-11-05 と 2026-11-07 の日付の要約例や、AI同士がつながるイメージのアニメーションが示される。

動画内では「重要な注意点がある」と述べるにとどまり、詳細はキャプション側への誘導。キャプションとコメント欄は「好きな数字をコメントすると詳細がDMで届く」集客形式で、コメント内に技術的な追加情報はない。

既存ノートとの関係: JARVIS構築そのものは @classified.ai（2026-11-14、5ステップ構成）など複数収録済みだが、本投稿は構築ではなく「他AIの会話履歴を取り込んで記憶を共有させる」という別主題・別作者のため新規収録した。
