# Claudeを使うなら最初に入れるべきSkill 10選

## 要約

リール（約46秒、内容は動画解析で確認）。韓国語で『Claudeを使うなら、このSkill 10個は入れてから始めて』と題し、GitHubで公開されているClaude用スキル10件を順に紹介する。01 find-skills（やることに合うスキルを探す。まずこれだけ入れておけば残りは検索してそのまま入れられる）02 grill-me（計画を問い詰めて明確にする）03 humanizer（AIっぽい表現26種を点検）04 caveman（回答を短くしてトークンを節約）05 handoff（長い会話を1枚の文書にまとめる）06 agent-browser（ブラウザを代わりに操作する）07 n8n-skills（自動化フローを組む）08 frontend-design（ありきたりなデザインから脱する）09 remotion（動画をコードで作る）10 real-sfx（実際に録音した効果音を載せる）。導入は `npx skills add` のコマンド1行が基本で、作者が実際に試したところ9件はコマンド1行で入ったが、最後の real-sfx だけ検索に出てこずフォルダごと入れる必要があったという。10件分のインストールコマンドはプロフィールリンクにまとめてある形式。動画内では各スキルのGitHubページとスター数も映るが、数値は投稿内表記で裏取りなし。既存ノートとの関係: caveman／humanizer／frontend-design／agent-browser は他のリスト系ノート（Lucas Acosta の「Claudeにインストールする21項目」、Anton の GitHub リポジトリ10選など）にも登場するが、find-skills を起点に実務寄りの10件を束ねた本投稿は別作者・別構成のため新規として収録した。
