# Higgsfieldを無料で使う「open-higgsfield-skills」（Claude Code＋ComfyUIで動画を自動生成）

- 日付: 2026-11-20
- 作者: はる@月1ディズニーパパ @haru_buzz.marke
- カテゴリ: 動画生成
- 元ネタ: https://www.instagram.com/reel/Df9Vz84z1c0/

## 要約

リール動画（内容は解析で確認）。動画生成AI「Higgsfield」を無料で使う方法として、オープンソースの「open-higgsfield-skills」（GitHub 上のプロジェクト、mojomast 作）を Claude Code から使う手順を紹介する内容。公式の Ultra プランは月額約50ドルかかるのに対し、この方法なら同等のことが無料でできる、という主張（金額は投稿内表記・裏取りなし）。

手順は4ステップ。1) ComfyUI Desktop をインストールする（Google Colab でも可）。2) GitHub リポジトリの URL を Claude Code に追加する。3) 不足している AI モデルを Claude に確認させ、ダウンロードさせる。4) `/video-director` コマンドにプロンプトを渡して実行する（動画内の例は「40代のママ向けに30秒の動画を作って」）。台本作成→画像生成→音声→字幕付けまでが自動化され、途中で編集もできると説明される。詳細なセットアップガイドはキャプション側への誘導形式で、動画内では手順の概要のみ。

注意点として、コメント欄では「無料化は誇張だ」とする検証コメントが目立つ。公式の通常の無料枠にはデイリークレジットがなく透かし（ウォーターマーク）が入ること、72時間無制限のキャンペーンはクレジットカード登録が必要で有料の Ultra プランへ自動移行すること、といった指摘で、コメント投稿者の調査に基づくもの（公式確認はしていない）。導入を検討する場合は無料範囲の条件を公式で確認したほうがよい。

既存ノートとの関係: Higgsfield 自体はライティングスタイル集（ai-picture）や Figma 系ノート（ui）で道具として登場しているが、「open-higgsfield-skills を Claude Code に入れて動画生成を自動化する」という主題は未収録のため新規収録した。同作者の既存ノート（Jarvis の記憶引き継ぎ、2026-11-07）とは別主題。
