## 要約

リール（約50秒、内容は動画解析で確認）。『次のリールを投稿する前に、この5つの無料 Claude Skill を入れて』と題し、SNS投稿づくりに効く Skill を5件紹介する。1. instagram-agent-skill（Jake Schincariol、MIT）: スキル13個＋フック公式26種＋フック採点ツール入り。投稿側のフックは93.8点、『Hey guys, in this video…』は0点と採点例を見せる。2. marketingskills（Corey Haines、MIT）: 53スキル入り。SNS向けスキルは『It's not X, it's Y』のような AI っぽい言い回しを禁止する決まりを持つ。3. remotion-dev/skills（Remotion 公式）: Claude が動画を React コードとして書く。4. remocn（MIT）: Remotion 用の既製アニメーション825種。このリール自体も3と4を使って作られている。5. skill-creator（Anthropic 公式）: 自分のベスト投稿3件を渡すと、自分の文体で書くための専用スキルを作れる。スター数（1は5,417、2は59,140など）はすべて投稿内表記で裏取りなし。導入リンク5件は『SKILLS』とコメントすると DM で送られる配布形式。Skill は Claude Code と Claude アプリ（Pro／Max／Team／Enterprise）で動くこと、導入前にスキル内のファイルを読むよう注意喚起があることにも触れている。末尾では作者自身の post2all スキル（Claude から15ネットワークへ投稿、月9ドル・7日間無料トライアル）も宣伝する。既存ノートとの関係: 1番の instagram-agent-skill は @almantiqi3 の回（2026-10-29）と @kento_ai_creator の回（2026-11-07）で単独収録済み。2番の Marketing Skills は『Claudeプラグイン30選』（@ai.byarsh）の Row 05 の1項目としても登場する。本投稿は SNS／リール制作向けに5件を束ねた別作者の別構成のため、新規として収録した。
