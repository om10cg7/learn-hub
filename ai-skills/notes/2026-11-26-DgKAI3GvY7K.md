## 要約

「話すだけでアプリをそっくりに作る」という Claude スキル「Craft Anything（クラフト・エニシング）」の紹介。原本を渡すと、眺めて→新しく作って→自分で点数まで付ける、という4段階：

1. **眺める** — ウェブサイト／デスクトップアプリ／ゲームを調べる
2. **作る** — 自分の Claude Code が新規に作る
3. **検査** — 原本と1つずつ比べて「似ている度」を％で採点
4. **磨く** — 点数が上がるまで直して再検査

動画内の例は PICK IT の AI クラスページ（点数画面は例示と明記）。資料（インストール、Claude Code 接続、最初の依頼文、点数の見方、著作権の注意）はフォロー＋コメントで DM 案内、PICKIT アプリの SNS 資料室107番で無料公開。

## 学び・所感

- 要点は生成そのものより「自己採点ループ」で、似ている度を％で数値化して改善の終了条件にしている点。Fable 5.2 のモーションデザイン回（ビジョン批評ループで8/10まで再レンダリング）と同じ「作る→見る→直す」の型を、クローン制作に適用したもの
- 資料に「著作権の注意」が含まれているのも実務的で、そっくりに作る系のスキルでは避けて通れない論点を最初から扱っている
