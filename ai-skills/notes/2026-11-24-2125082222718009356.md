## 要約

X投稿（2026-11-24 13:20、添付は字幕見本付きの一覧画像1枚）で提示された、Claude Code で商品レビュー動画を編集するときにそのまま送れる「動画テロップの直し方20選」。主張は、「テロップを見やすくして」のような曖昧な頼み方では直したいところが伝わりにくく、どの場面で何を見せたいか（症状と場所）まで言葉にするのがコツ、というもの。たとえば「白い服の上で字幕が消える」ならフチ文字の指示に、「大事な一言がほかの字幕に埋もれる」ならマーカー塗りの指示に、「比較映像のどちらが補正オンか分からない」なら比較テロップの指示に落とし込む。

## 20選（名称 ― 指示の要点）

| # | 項目 | 指示の要点 |
|---|---|---|
| 01 | 文節で改行 | 商品名は途中で切らない |
| 02 | 強制アラインメント | 字幕の出だしを話し始めに合わせる |
| 03 | フィラー除去 | 「えー」「あの」だけ外す |
| 04 | 1枚1メッセージ | 感想ごとに字幕を分ける |
| 05 | 表記ゆれ統一 | 表記を全編で統一する |
| 06 | フチ文字 | 白文字に濃いフチを付け、白い服の上でも読めるようにする |
| 07 | 座布団 | 明るいカットだけ字幕の下に半透明の黒帯を敷く |
| 08 | 安全領域 | 操作ボタンや説明欄に重ならない位置に置く |
| 09 | 強調語の色替え | 強調したい語だけ色を変える |
| 10 | 顔を避けて配置 | 顔と商品を避けて字幕を置く |
| 11 | ポップイン | 結論の一言だけ少し大きく出す |
| 12 | カラオケ字幕 | 発話に合わせて語ごとに色を変える |
| 13 | イーズアウト | 止まる直前だけ速度を落とす |
| 14 | ビート同期 | 切り替えの拍に合わせて名前を出す |
| 15 | マーカー塗り | 結論の瞬間にキーワードの下をマーカーでなぞる |
| 16 | 補足テロップ | 撮影条件を小さく添える |
| 17 | 数字テロップ | グラム数だけ大きく出す |
| 18 | 注釈テロップ | 加工カットに「色調整あり」と添える |
| 19 | 価格テロップ | 税込か税抜かを添える |
| 20 | 比較テロップ | オンとオフを左右に並べ、同じ位置にラベルを付ける |
