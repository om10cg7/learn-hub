## 固有の実務情報

- **ライセンス**: 14件中13件が MIT か Apache-2.0。Blender のみ GPL だが、Blender でレンダリングした成果物は自分のものになる、との注記。
- **メンテナンス注意**: TweenJS は2023年12月、gifenc は2024年9月からコミットなし。どちらも動作はするが、使うならバージョンを固定（pin）すること、と注意喚起している。
- **サンプルプロンプト**: Claude Code に貼る前提の指示文が付属。要点は、Fable 5.2 を監督役として15秒の商品ループ動画をブラウザで作るもので、Motion＝UI遷移、Anime.js＝メインマイライン、Two.js＝ベクター図形、Three.js＝3Dの主役オブジェクト1つ、Proton＝見せ場のパーティクル、と役割を割り当て、まず全ビートのフレーム番号を出させてから、1080x1350・30fps でレンダリングし、gifenc で GIF プレビューも作らせる、という構成。
- 制作フローは brief → build → animate → refine → render。
