## 要約

X投稿（ペルシャ語、投稿日時 2026-11-17 04:11 表示、添付は16秒の紹介動画）で紹介された、動画制作・編集用の Skill／ツール12件を4グループ（STUDIO／CUT／STYLE／MOTION & SOUND）に分けたリスト。作者は「動画は全部 Claude Code で編集した。ビデオエディタも CapCut も使っていない」と主張し、従来の動画編集ソフトを使わず Claude Code とこれらの道具だけで編集まで回す前提の顔ぶれになっている。始め方として `npx skills add hypit-ai/hypit` のようなコマンドで Skill を追加する形が提示されている。投稿には各リポジトリのスター数（例: OpenMontage 80.1K）が併記されているが、いずれも投稿内表記で裏取りなし（実在性・数値とも未確認のため断定しない）。作者の自己返信はログイン制限のため未確認。
