## 要約

X投稿（2026-11-25 11:48、添付は動画22秒）。「I copy any UI I see now, these 15 GitHub repos are the reason」「a f*cking gold for Fable 5.2」と題し、Fable 5.2（Claude系エージェント）にUIを作らせるためのGitHubリポジトリ15件を挙げたリスト。デザインSkill、コンポーネント基盤、アニメーション、チャートまで、UI構築の工程をカバーする。締めは工程の合言葉「Skill → component → style → animate → chart → shipped」と、「Bookmark this and send the list to your Claude」（ブックマークしてリストを自分のClaudeに送れ）という呼びかけ。

添付動画は、15リポジトリのUIコンポーネントカードを並べたボードをゆっくり縦スクロールするショーケース。

同系統のリストとして、@0xnicc0「Fable 5.2で3Dアニメーションを作るためのGitHubリポジトリ12選」（2026-11-25）も ai-skills に収録済みで、こちらはUI構築版にあたる。
