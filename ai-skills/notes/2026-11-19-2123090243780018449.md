## 要約

X投稿（添付は縦長動画1件、内容はサムネイル範囲のみ確認、再生・音声は未確認）で紹介された、Claude Fable 5.2 と TradingView を組み合わせた AI トレード環境の構築例。最大のポイントは「AI にチャート画像を見せるのではない」という設計で、TradingView 上のインジケーターが計算した数値情報をそのまま Claude Code 側に渡して判断させる。

構成は次の通り。インジケーター側が確定したローソク足ごとに LONG スコア／SHORT スコア、エントリー、損切り、利確を計算する。その情報を Claude Code に渡し、Claude が LONG／SHORT／WAIT を判断する。損切り・利確の位置、ポジションサイズ、その根拠も Claude が提示し、過去チャートでの自動検証（バックテスト）までつなげる、という流れ。

成績として、BTC 1時間足・2026-11-01〜18 の期間で勝率55%・PF 2.19・+4.5% という数値が示されているが、これは投稿内表記であり裏取りはしていない（第三者による検証なし）。
