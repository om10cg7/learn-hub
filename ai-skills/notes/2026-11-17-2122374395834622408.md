# Claude Codeで3モデルを分業させる構成（Sonnet主担当＋Haikuサブエージェント＋Opus顧問）

- カテゴリ: Claude Code

## 要約

X投稿（中国語、投稿日時 2026-11-17 02:01 表示、添付は36秒の構成図アニメーション動画）で紹介された、Claude Code で3モデルを役割分担させる構成方法。起動コマンドは投稿内表記で `claude --model sonnet --advisor opus`。分業の中身は、Sonnet 5.5 が主会話としてコード作成とバグ修正を担い、Haiku 5.5 がサブエージェントとして倉庫検索・grep・diff 審査を並行実行し、Opus 5.5 は顧問として待機して重要な判断だけを担当する、という三層構成。Opus が介入する節目は3つに限定されていて、方針を確定する前、同じエラーが2回目に出たとき、完了を宣言する前の3時点で入り、最終的には diff に「署名」して承認する流れになっている。さらに「JEV」という層があり、ファイル選択・ツール選択・再試行の可否といった判断不要の分岐をミリ秒級に処理する、と投稿は主張している。

設定方法として、Claude Code にそのまま貼る設定用プロンプトが本文に用意されている。要点は、主会話を Sonnet＋顧問 Opus の構成にすること、`.claude/agents` に Haiku のサブエージェントを3つ（search・grep・audit）作ること、audit には `isolation: worktree` を付けること、CLAUDE.md に「倉庫検索とテストは Haiku サブエージェントへ回す」という規則を追加すること、分岐処理は JEV に任せること、そして変更は diff を見せて承認を得るまではファイルを変更しないこと。

なお、投稿がリンクする Claude Code 公式ドキュメントの sub-agents ページ（https://code.claude.com/docs/en/sub-agents）で確認できるのは、サブエージェントの仕組みそのもの（独立コンテキスト、`.claude/agents` への Markdown 配置、モデル選択、`isolation: worktree`）まで。`--advisor` フラグと JEV は公式ドキュメントでは確認できておらず、モデル名の「5.5」という表記も含め、投稿内の主張（作者表記ママ）として扱う。

追記（2026-11-17）: その後、Claude Code 公式ドキュメントの advisor tool のページ（https://code.claude.com/docs/en/advisor）で、advisor tool の実在と `/advisor` および `claude --advisor` による指定方法が確認できた（実験的機能、v2.1.300 以降）。JEV は引き続き公式未確認。同じ advisor 構成を長時間ハーネスの文脈で扱う @N01ennn の投稿を別ノートとして収録した（notes/2026-11-17-2122382693732065301.md）。

## 追記（2026-11-18）

別作者 @skunzu の投稿（https://x.com/skunzu/status/2122403952377360423、2026-11-17）が同じ構成（Sonnet 主会話＋Haiku の search/grep/test-runner＋Fable advisor＋JEV）の再展開だったため、重複として新規ノートは作らず、本ノートにない細部をここに追記する。

- **advisor の動き方の明示**: 介入タイミングは本文の3時点（計画が確定する直前／同じエラーが2回目に出たとき／タスクを完了と宣言する前）と同じだが、@skunzu の投稿では advisor 役が Fable 5.2 で、その動きがより具体的に説明されている。Fable はコードを書かず、セッション全体のトランスクリプト（全ツール呼び出しと結果）を読んで、短い判定だけを主モデルに返す。ユーザーには直接話さない。主モデルは判定を受けて修正することも、同じトランスクリプトを見ている立場から反論することもできる。つまり advisor は「第二の手」ではなく「第二の意見」だという位置づけ。
- **再現用プロンプト全文**（@skunzu の投稿掲載ママ。本文の設定用プロンプトとは別バージョンで、advisor が Fable、Haiku サブエージェントが search／grep／test-runner の構成）:

  > Rebuild my Claude Code setup around this tree:
  > 1. Run the main session on Sonnet 5.5 with Fable 5.2 as advisor.
  > 2. Create three read-only Haiku 5.5 subagents: search (maps the repo), grep (finds call sites), test-runner (runs the suite, reports only failures).
  > 3. Add one rule to CLAUDE.md: consult the advisor before a plan locks, after the same error twice, and before a task is marked done.
  > 4. Route fast deterministic forks (tool choice, path selection, retries) through JEV.
  > Show me every change as a diff first. Nothing gets edited until I say go.

- **公式ドキュメント由来の注意点**: advisor の利用もプランの上限にカウントされる。またプランによっては、Fable を advisor にすると usage credits への課金になる場合がある。導入手順としては、`claude update` を実行したあと `/model fable` を一度実行して承諾する流れが紹介されている。
