# 一文の指示でClaude Codeが30秒CMを「一発出し」— HTML/GSAP→HyperFrames→FFmpegのパイプライン

- 日付: 2026-09-28
- 作者: TAKU｜映像制作×オンライン秘書（@taku_creative.film）
- カテゴリ: 動画生成
- 元ネタ: https://www.threads.com/@taku_creative.film/post/Dd0zKjzD0i4

## 要約

Xで話題のモーショングラフィックス手法を試し、動画編集ソフトを使わずに自社CM（30秒）を「一発出し」で作ったという作例投稿（動画）。キャプションでは使用モデルを「Opus 5.5」と冗談交じりに表記している（投稿内表記）。

作者本人の返信で、使ったプロンプトと仕組みの両方が公開されている。

使ったプロンプトは会社名・URLを差し替えるだけの一文で、「○○（会社名・URL）の魅力が伝わる、ダイナミックな30秒のCMをモーショングラフィックスで作ってください。会社について調べて、公式の事実と素材だけを使って。一流の映像会社の作品のように、全力でやって。」という内容。会社情報のリサーチから素材の使用までを Claude Code 側に委ねる設計。

仕組み（作者の解説）: ①映像はWebページとして作る。各シーンの文字・写真・図形の配置はHTML/CSS、動き（いつ・どこへ・どんな速さで）はJavaScriptのアニメーションライブラリGSAPで記述。②HyperFramesが、画面を表示しないChromeでそのページを開き、時間を1/30秒ずつ進めながら900コマ（30秒×30fps）を画像として取り込む。③取り込んだコマと音声をFFmpegでMP4にまとめる。④音声もプログラム生成で、仮BGMはPython（numpy）でキック・ベース・和音などを計算して作った音、効果音は同梱素材をタイミングどおりに並べたもの。

プロンプト自体は汎用の一文で、主役は「Claude CodeにHTML/GSAPで映像を組ませ、HyperFrames＋FFmpegで動画化する」という仕組みのため ai-skills に収録した。HyperFrames自体は既存ノート（Claude動画スキル系）にも登場するが、本投稿は一文プロンプト＋全工程の解説がセットの別作者・別投稿のため新規収録。
