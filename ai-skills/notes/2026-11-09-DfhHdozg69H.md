## 要約

「もうAdobeにお金を払う必要はありません。」— Adobe Creative Cloud の代替として、無料・オープンソースのクリエイティブアプリ群「ArtCraft」を紹介する約42秒のリール。発表者が getartcraft.com のサイトを見せながら7アプリを紹介する。

紹介された7アプリ（対応するAdobeアプリ）:

1. PhotoCraft — Photoshop
2. VectorCraft — Illustrator
3. FilmCraft — Premiere Pro
4. LightCraft — Lightroom
5. EffectCraft — After Effects
6. PdfCraft — Acrobat
7. DesignCraft — InDesign

リールで強調される特徴:

- Rust で一から開発、MIT/Apache-2.0 ライセンスのオープンソースでコードは GitHub 公開
- サブスクリプション・ログイン不要、完全オフライン動作でファイルはローカルに残る
- PSD など標準ファイルを開ける（画面では PhotoCraft が PSD を開く様子を紹介）
- バージョン 0.20.2 が macOS / Windows / Linux / Web で無料

## 背景・補足

- 開発者は Brandon Thomas。Claude Opus 5.5 を使ってクリーンルームで再実装したもので、Adobe の解約手数料が開発のきっかけとされている（複数報道で確認）。
- 2026年11月7日時点の報道では、ラインナップは16アプリまで拡大している（TextureCraft、MaterialCraft、Craft Anything などが追加）。本リール（11月9日投稿）ではサイト上の7アプリを紹介している。
- 動画の締めは「Adobe の代替に興味がある人はコメントして」という呼びかけ。コメントは8件。

## 注記

- リールの主張は「Adobe にお金を払う必要なし」だが、複数報道によれば各アプリは早期アルファ段階で、プロ用途では機能不足や不具合の指摘がある。「Photoshop を今すぐアンインストールできる」段階ではない点に注意。
