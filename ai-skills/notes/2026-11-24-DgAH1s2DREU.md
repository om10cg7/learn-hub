## 要約

カルーセル（内容はメディア理解で確認）。Claude Code の Skills の中から、Webサイトやアプリなど視覚要素の強い制作向けに5つを選んだ回。すべて公開 GitHub リポジトリで無料・無償紹介と明記。インストールコマンド5つと使用プロンプトは「DESIGN」コメントで送付（未回収、コピーボタン対象外）。

| # | Skill（リポジトリ） | 内容 |
|---|---|---|
| 1 | Three.js（CloudAI-X/threejs-skills） | インタラクティブな3Dシーン。カメラ、照明、パーティクル、GLTFモデルまで一式 |
| 2 | GSAP（greensock/gsap-skills） | 高級サイトの滑らかなアニメーション。スクロール効果、テキストリビール、タイムライン、トランジション。ScrollTrigger や React 連携 |
| 3 | Design DNA（zanwei/design-dna） | 好きなサイトのデザインを解析し、色・タイポグラフィ・余白・レイアウトを再利用できるデザイントークンに抽出 |
| 4 | Motion Design（lottiefiles/motion-design-skill） | LottieFiles チーム製。Lottie と SVG アニメーション、キーフレーム、そのまま書き出し |
| 5 | Genjutsu（AThevon/genjutsu） | 最後のデザインパス。現代的なUIパターン、レイアウト改善、磨き上げの細部 |

組み合わせの提案も具体的：Design DNA が視覚の方向を決め、GSAP と Motion Design が動き、Three.js が奥行き、Genjutsu が最終の磨き。迷ったら最初は Design DNA から、と推している。前提として「Skills はプロンプトではなく、一度入れればセッションをまたいで使える」という説明付き。

## 学び・所感

- 5つの並べ方が工程順（方向づけ→動き→奥行き→仕上げ）になっていて、単体の紹介ではなく「一緒に使う」設計になっているのが要点
- Design DNA の「好きなサイトからトークンを抜く」という発想は、AIにデザインを頼むときの最大の曖昧さ（好みの伝達）を、参照URL＋トークン化で解消する実務的な手
