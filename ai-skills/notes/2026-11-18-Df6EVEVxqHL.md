## 要約

Anthropic公式のベストプラクティスとして紹介された、Claude Codeの使い方9選（約82秒のリール）。同じClaude Codeでも使い方次第で成果物の精度が変わる、という趣旨。9項目の詳しい使い方はDM限定配布（フォロー＋いいね＋コメント）のため全文は未取得で、ここではリール映像で確認できた要点のみを収録する。

| # | 使い方 | 要点 |
|---|---|---|
| 1 | CLAUDE.mdは200行以下に | 行数を抑えてトークン使用量を減らす |
| 2 | 作る前にプロのやり方を調べさせる | 着手前に「プロがどうやるか」をリサーチさせる |
| 3 | 依頼は目的・ルール・ゴールだけ | 依頼時に伝えるのは目的、ルール、ゴールの3つに絞る |
| 4 | /effortをタスクで調整 | 軽い作業は low、複雑な判断は high に切り替える |
| 5 | 分からないときは先に質問させる | 推測で進めず、不明点は質問してから着手させる |
| 6 | 別モデルにレビューさせる | 成果物を別のAIモデルにチェックさせる |
| 7 | /goalに完了条件を書く | 完了条件を明記し、満たすまで繰り返させる |
| 8 | 大きな仕事はサブエージェントへ | 大きな仕事を分割してサブエージェントで並行処理する |
| 9 | 重要なルールはHooksで強制 | CLAUDE.mdに書くだけでなくHooksで強制する |

「CLAUDE CODE 100倍 賢くなる」という冒頭の表現や、作者の実績主張（総フォロワー10万人、億超企業のSNS×AI顧問、Brain人気記事ランキング最高8位など）は投稿内表記で、裏取りはしていない。なおキャプションではコメントに「好きな色」とあるが、動画の最後では「オレンジ」とコメントするよう案内しており、食い違いがある（動画ベースで記載）。同作者の既存ノート「Claude Code 神機能 7選」（2026-10-30）はカレンダー連携やClaude in Chromeなどの連携機能中心で、本稿の使い方9選とは題材が異なり重なりはない。
