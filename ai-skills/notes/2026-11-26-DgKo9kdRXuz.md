## 要約

「Claudeに動画を作らせて『正直しょぼい…』となった人へ」— GitHub にある無料ツールを入れていないだけ、という切り口で、実際に入れて作ってみた5つをランキング形式で紹介。入れ方は共通で、Claude Code に GitHub の URL を貼って「これ入れて」と言うだけ。詳しい手順書は「動画」コメントで DM 送付（未回収、コピーボタン対象外）。ツールは無料、Claude Code は有料プラン前提。

| 順位 | ツール | 内容（キャプション） |
|---|---|---|
| 5 | Blender MCP | 「岩や草で、ビーチの雰囲気にして」の一言で無料の3Dソフト Blender に場面を作る（先に Blender 本体のインストールが必要） |
| 4 | awesome-opus5-5-videos | バズった動画とプロンプトが700個以上。コピーして貼るだけで試せる |
| 3 | rea-video | 参考にしたい動画を1カットずつ分解。BGMや効果音の位置、作り直し方まで出す |
| 2 | lemo-opuscar | 水彩・浮世絵・ドット絵など99種類のスタイル。絵も音楽も全部コードで作る |
| 1 | HyperFrames | HeyGen が出した無料ツール。言葉で頼むと動画になり、あとから1コマずつ直せる |

既存ノート「Claude動画制作ツール5選」（@ippeimatsuo、2026-11-24）と HyperFrames と Lemo Opuscar の2つが重なるが、残り3つと「実際に試したランキング」という形式が違うため別ノートとする。

## 学び・所感

- 3位 rea-video の「参考動画の分解」は、生成の前段（分析）を担う部品で、バズ動画のプロンプト集（4位）と合わせて「真似るための材料と分解」を揃える発想になっている
- 1位と2位が前回（松尾一平の回）と同じ顔ぶれで、この2つが現在の定番として固まりつつあることも読み取れる
