- 日付: 2026-11-16
- 作者: Dumble @Y0urDumble
- カテゴリ: GitHub
- 元ネタ: https://x.com/Y0urDumble/status/2122315145250582727

## 要約

X投稿（2026-11-16 22:05 表示、添付は20秒のツールカード・モンタージュ動画）で紹介された、「Opus 5.5 をモーションスタジオに変える」ための GitHub リポジトリ20選。作者の主張は、すべて無料・オープンソースでローカル実行でき、レンダーごとの課金がない、という点。工程の流れは末尾の表記「Idea → animate → sound → render」で、アイデア出しからアニメーション、音付け、書き出しまでをこの20件でつなぐ構成になっている。内訳は、アニメーション生成（AnimateDiff／OpenToonz）、補間・編集（RIFE／OpenCut）、Web モーション（Animate.css／PixiJS／Vivus／Mo.js／Rough.js）、3D・VR（A-Frame／3D Gaussian Splatting／CesiumJS）、AI 動画まわり（ComfyUI／LivePortrait／SAM 2／Rembg）、音声（Whisper／AudioCraft／Fish Speech）、最終書き出し（HandBrake）。

## 関連: 引用元の X Article

この投稿は、作者の過去投稿（2026-10-28、65秒カートゥーンが8日で2700万再生という形式分析）と、その X Article「How to build a 2.5D motion studio with Opus 5.5 (Full Course)」を引用している。記事は2.5D形式の再現コースで、形式の定義は 1080x1920・30fps・65秒・2Dキャラ＋ライティングされた3Dセット・約2秒ごとに新ショット・スローなドリー・1〜2語の字幕。手順は、ffmpeg でのリファレンス分解、CLAUDE.md のハウスルール、150〜170語の台本、Blender を MCP 経由で構築、SVGキャラ、Whisper の単語タイムスタンプ字幕を Remotion で載せる、レビューループまで。なお「2700万再生」などの数値は記事内・投稿内の表記で、裏取りはしていない。
