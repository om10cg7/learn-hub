## 要約

「Turn Claude into a Video Editor — You need just 15 free GitHub repos」。Claude を動画編集者に仕立てるための無料 GitHub リポジトリ15件を、5×3のグリッドで名前・所有者パス・スター数・機能アイコン付きで並べた1枚。全リストは「VIDEO EDITOR」コメントで送付（未回収、コピーボタン対象外）。メディア理解で名前が読み取れたのは次の10件で、残り5件は未回収：

yt-dlp、Whisper、FFmpeg Skill、Ghost Editor、Claude Shorts、Three.js Skills、Motion Skills、MotionClone、HyperFrames、Awesome Skills

コメント欄では「Whisper と FFmpeg が要で、判断は人間の側に残る」という指摘があり、作者も DM 送付で応答していた。

## 学び・所感

- 顔ぶれは「素材取得（yt-dlp）→文字起こし（Whisper）→加工（FFmpeg）→動き付け（Motion 系／HyperFrames）」という編集工程の部品集で、Claude 本体はそれらを束ねる指揮役という構図。単体の動画生成AIではなく、既存の無料ツールを Skill で接続する発想
- 既存ノートの「Claude動画制作ツール5選」（@ippeimatsuo）にも HyperFrames が重なって登場しており、この分野の定番部品になりつつある
