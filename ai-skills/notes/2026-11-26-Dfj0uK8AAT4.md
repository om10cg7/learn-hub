## 要約

「YouTubeはもうClaudeで全自動化できるよ」— YouTube 運用を Claude に任せる「YouTube Agent Skill」の紹介。動画作成、タイトル、サムネイル、コメント、分析、投稿計画まで全部 Claude が担当し、作業は1日30分ほど、という主張。Skill 本体（GitHub リンクと使い方ガイド）はフォロー＋「欲しい」コメントで DM 配布（未回収、コピーボタン対象外）。

含まれる11スキルのうち、メディア理解で名前が確認できたもの：

| コマンド | 役割 |
|---|---|
| /yt-script | バズ動画を分析して台本を書く |
| /yt-package | サムネイル作成 |
| /yt-edit | フィラーワードを切る自動編集 |
| /yt-comment | コメント返信 |
| /yt-plan | 週の投稿計画 |
| /yt-viral | バズのトレンド調査（上位動画を要約し新企画を出す） |

注意点：動画内の「YouTubeだけで月約72万円」という収益の主張は本人のもので裏取りなし。コメント欄にはスパム／フィッシングを警告する声もあり、配布リンクの安全性は未確認。同じ作者の Instagram 自動化の回（既存ノート）でも収益は本人の主張として扱った。

## 学び・所感

- 構造は「チャンネル運用の工程をコマンド単位の Skill に割る」もので、企画（/yt-viral、/yt-plan）→制作（/yt-script、/yt-package、/yt-edit）→運用（/yt-comment）という工程分解自体は、AIRA CODE や The Harness の部署型と同型
- ただし本人の運用方針（投稿は下書き提示＋明示承認のみ、完全自動投稿はしない）とは相容れない部分が大きく、取り入れるなら生成と下書きまでが現実的な範囲、という線引きは前回と同じ
