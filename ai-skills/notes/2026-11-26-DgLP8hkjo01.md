## 要約

カルーセル（内容はメディア理解で確認）。「Claude Code に1行打つだけ。Paper Studio が紙切り絵の映画を作る」という告知で、全スライドが「打った題材は1行だけ」という前提で並ぶ。入手は「PAPER」コメントで送付（未回収、コピーボタン対象外）。

作例7本：

1. 1755年リスボン（大地震の波）
2. 海から島が隆起する（1963年スルツェイ島の噴火）
3. ピラミッド建設（ランプを運ぶ古代エジプトの労働者）
4. ヴェネツィア（なぜ沈まないのか、夕景）
5. 空が燃えた夜（1859年キャリントン・イベントのオーロラ）
6. 巨大な藁のヤギ（スウェーデンのイェヴレ・ゴート、雪の広場）
7. ハチミツの瓶の広告（Meadowhum のワイルドフラワーハニー、パンケーキ）

歴史・科学の題材から商品広告までを同じ紙切り絵の様式で通す、教育系ショート動画の量産を想定した見せ方。

- 同じ作者の既存ノート（紙切り絵リスボン、Claude→ChatGPT→Omni Flash の3ツール分業）とは別物で、こちらは Claude Code 内の単体ツールとして題材1行から完結させる形。手作業の工程紹介から「製品化された1行入力」への移行が見える
