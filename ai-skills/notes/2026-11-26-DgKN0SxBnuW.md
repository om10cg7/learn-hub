## 要約

「ひとりで、マーケティング部をまるごと回す。そのAIチームの設計図を、全部見せます」— 自作ツール「The Harness Cloud」（theharness.cloud）の紹介。Claude Code と Codex を基盤に、X／Instagram／Threads／LINE のデータを一元化し、5つのチームが24時間動く仕組み。設計図の全体図は「設計図」コメントで DM 送付（未回収、コピーボタン対象外）。Google アカウントで無料開始（カード不要）と案内していた。

5チームの流れ：

1. **リサーチ＆台本** — トレンド収集、バズ投稿の分析、台本作成
2. **投稿** — 最適な時間にスケジュール投稿
3. **コメント・DM** — 「設計図」のようなキーワードコメントを検知して DM を自動送信し、LINE へ誘導
4. **育成・予約** — LINE でステップ配信、自動ウェビナー、事前ヒアリング、予約受付
5. **分析ループ** — どの投稿が予約に繋がったかを追い、結果をリサーチへ還元

人間がやるのは朝の承認と個別相談への出席だけ、という設計。

## 学び・所感

- AIRA CODE の「AI社員13人」（ai-skills 収録済み）と同型の「部署ごとAIチーム」構成だが、こちらは SNS の先に LINE の育成・予約までを1本の導線として繋いでいるのが違い。分析も「再生数」ではなく「予約に繋がった投稿」を追う設計で、ゴールを売上側に置いている
- コメント検知→DM→LINE誘導という、自分自身の集客導線そのものが製品の実演になっている点も構造として巧い
